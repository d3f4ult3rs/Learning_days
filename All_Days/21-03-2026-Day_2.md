## 🟨 JavaScript Fundamentals

### 🔁 Loops

**1. while loop**  
Executes code **as long as condition is true**
```javascript
let i = 0;
while (i < 5) {
  console.log(i);
  i++;
}
```

2. do-while loop
Executes at least once, then checks condition
```javascript
let i = 0;
do {
  console.log(i);
  i++;
} while (i < 5);
```

3. for loop
Best for fixed iterations
```javascript
for (let i = 0; i < 5; i++) {
  console.log(i);
}
```
