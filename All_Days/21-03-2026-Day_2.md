## 🟨 JavaScript Fundamentals

### 🔁 Loops

**1. while loop**  
Executes code **as long as condition is true**
```javascript
let i = 0;
while (i < 5) {
  console.log(i);
  i++;
}
```

**2. do-while loop**
Executes at least once, then checks condition
```javascript
let i = 0;
do {
  console.log(i);
  i++;
} while (i < 5);
```

**3. for loop**
Best for fixed iterations
```javascript
for (let i = 0; i < 5; i++) {
  console.log(i);
}
```

### ⚡ Nullish Coalescing Operator (??)

Used to provide a default value when variable is null or undefined

let username = null;
let displayName = username ?? "Guest";

console.log(displayName); // Output: Guest

✅ Difference from ||:

?? only checks null or undefined
|| checks all falsy values (0, "", false, null, undefined)

## 🔍 GraphQL Language Concepts
### 🏷️ Operation Name

Used to name a query for better debugging and clarity
```GraphQL
query GetUser {
  user(id: "1") {
    name
  }
}
```

### ⚙️ Operation Type

Defines what action is performed:

- query → Read data
- mutation → Modify data
- subscription → Real-time updates

### 📥 Arguments

Used to pass input to queries
```GraphQL
query {
  user(id: "1") {
    name
  }
}
```

### 🔄 Aliases

Rename fields in response
```GraphQL
query {
  firstUser: user(id: "1") {
    name
  }
}
```

### 🧩 Fragments

Reusable query parts
```GraphQL
fragment userFields on User {
  name
  email
}

query {
  user(id: "1") {
    ...userFields
  }
}
```
### 🎯 Variables

Dynamic input instead of hardcoding values
```GraphQL
query GetUser($id: ID!) {
  user(id: $id) {
    name
  }
}
```
