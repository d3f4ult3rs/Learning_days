1. 🔌 WebSocket Vulnerabilities

Today I learned about WebSockets and their security risks.

📌 What is WebSocket?
WebSocket is a protocol that provides full-duplex (two-way) communication between client and server over a single connection.

⚠️ Common WebSocket Vulnerabilities:
1. Lack of Authentication: If WebSocket connections are not properly authenticated, attackers can connect and interact freely.
2. Origin Validation Issues: Missing or weak origin checks can allow Cross-Site WebSocket Hijacking (CSWSH).
3. Sensitive Data Exposure: Data sent over WebSocket may not be encrypted or validated properly.
4. Message Injection / Manipulation: Attackers can send malicious payloads if input validation is weak.
5. No Rate Limiting: Can lead to abuse like spam or brute-force via persistent connection.
